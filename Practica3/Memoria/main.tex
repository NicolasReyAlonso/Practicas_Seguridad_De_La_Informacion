\chapter{Conclusiones}

\section{Resumen de aprendizajes}

A través de esta práctica se han consolidado los siguientes conceptos:

\begin{enumerate}
    \item \textbf{Criptografía asimétrica RSA:} Generación de pares de claves, exportación entre formatos (PEM, DER), y la importancia de proteger las claves privadas con contraseña.
    \item \textbf{Firma digital:} Uso de resúmenes SHA-256 firmados con clave privada para garantizar integridad y autenticación del origen.
    \item \textbf{DSA:} Algoritmo de firma digital alternativo a RSA, con generación de parámetros independiente de la generación de claves.
    \item \textbf{Diffie-Hellman:} Protocolo de intercambio de claves que permite derivar un secreto compartido sin transmitirlo directamente.
    \item \textbf{ECDH con X25519:} Curvas elípticas que logran seguridad equivalente con claves significativamente más pequeñas.
    \item \textbf{Intercambio seguro:} Combinación de cifrado simétrico (AES-256-CBC), cifrado asimétrico (RSA) y firma digital para lograr confidencialidad, integridad y autenticación.
\end{enumerate}

\section{Recomendaciones de seguridad}

Para aplicaciones reales:

\begin{enumerate}
    \item \textbf{Tamaño de claves RSA:} Mínimo 2048 bits; preferir 4096 bits para mayor seguridad a largo plazo.
    \item \textbf{Protección de claves privadas:} Siempre cifrar con contraseña; evitar formatos DER para almacenamiento.
    \item \textbf{Curvas elípticas:} Preferir X25519/Ed25519 por su eficiencia y seguridad.
    \item \textbf{Firma digital:} Usar SHA-256 o superior como función de resumen.
    \item \textbf{Intercambio de claves:} Combinar cifrado simétrico + asimétrico (esquema híbrido) para eficiencia.
    \item \textbf{Verificación:} Siempre verificar la firma antes de confiar en el contenido descifrado.
\end{enumerate}

\section{Problemas encontrados y soluciones}

\begin{itemize}[label=\textbullet]
    \item \textbf{Formato DER y contraseñas:} La conversión a DER elimina la protección con contraseña, lo cual hay que tener muy en cuenta al exportar claves privadas.
    \item \textbf{Parámetros DH compartidos:} Ambos pares de claves DH deben usar los mismos parámetros para poder derivar un secreto común.
    \item \textbf{Tamaño de datos RSA:} RSA solo puede cifrar datos menores al tamaño de la clave (por ejemplo, 256 bytes para RSA-2048), lo que justifica el esquema híbrido.
    \item \textbf{Verificación con \texttt{-verifyrecover}:} Es necesario usar esta opción (exclusiva de RSA) para recuperar el resumen original de una firma y compararlo manualmente.
\end{itemize}

\appendix

\chapter{Comandos OpenSSL Utilizados}

\section{Generación de claves}

\begin{lstlisting}[caption=Comandos para generación de claves]
# RSA: Generar par de claves con contraseña
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 \
    -aes-256-cbc -pass pass:"contraseña" -out privkey.pem

# Exportar clave pública
openssl pkey -in privkey.pem -passin pass:"contraseña" \
    -pubout -out pubkey.pem

# Exportar a DER
openssl pkey -in privkey.pem -passin pass:"contraseña" \
    -outform DER -out privkey.der

# DER a PEM
openssl pkey -in privkey.der -inform DER -out privkey_nopass.pem
\end{lstlisting}

\section{Firma y verificación}

\begin{lstlisting}[caption=Comandos para firma digital]
# Crear resumen SHA-256
openssl dgst -sha256 -binary -out digest.bin archivo.txt

# Firmar resumen
openssl pkeyutl -sign -in digest.bin \
    -inkey privkey.pem -passin pass:"contraseña" \
    -out firma.bin

# Verificar firma
openssl pkeyutl -verify -in digest.bin \
    -sigfile firma.bin -pubin -inkey pubkey.pem

# Recuperar resumen de la firma (solo RSA)
openssl pkeyutl -verifyrecover -in firma.bin \
    -pubin -inkey pubkey.pem -out resumen_recuperado.bin
\end{lstlisting}

\section{Derivación de secretos}

\begin{lstlisting}[caption=Comandos para derivación DH y X25519]
# DH: Generar parámetros
openssl genpkey -genparam -algorithm DH \
    -pkeyopt dh_paramgen_prime_len:2048 -out dh_params.pem

# DH: Generar claves con parámetros
openssl genpkey -paramfile dh_params.pem -out dh_priv.pem
openssl pkey -in dh_priv.pem -pubout -out dh_pub.pem

# Derivar secreto compartido
openssl pkeyutl -derive -inkey priv1.pem \
    -peerkey pub2.pem -out secreto.bin

# X25519: Generar claves
openssl genpkey -algorithm X25519 -out x25519_priv.pem
openssl pkey -in x25519_priv.pem -pubout -out x25519_pub.pem
\end{lstlisting}

\section{Cifrado asimétrico y conversión BASE64}

\begin{lstlisting}[caption=Comandos para cifrado asimétrico]
# Cifrar con clave pública RSA
openssl pkeyutl -encrypt -in datos.txt \
    -pubin -inkey pubkey.pem -out datos.bin

# Descifrar con clave privada RSA
openssl pkeyutl -decrypt -in datos.bin \
    -inkey privkey.pem -passin pass:"contraseña" \
    -out datos_descifrados.txt

# Convertir binario a BASE64
openssl enc -a -in datos.bin -out datos.txt

# Convertir BASE64 a binario
openssl enc -a -d -in datos.txt -out datos.bin
\end{lstlisting}
