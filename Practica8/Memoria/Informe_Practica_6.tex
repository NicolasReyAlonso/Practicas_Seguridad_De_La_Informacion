\chapter{Modificación del fichero hosts}
Se modifica el fichero \texttt{/etc/hosts} para añadir los alias.
\begin{lstlisting}[language=bash]
127.0.0.1 www.ejemplo.com
127.0.0.1 ejemplo.com
\end{lstlisting}
Verificamos:
\begin{lstlisting}[language=bash]
ping -c 2 www.ejemplo.com
ping -c 2 ejemplo.com
\end{lstlisting}


\chapter{Incorporación del certificado RAÍZ}
Se incorpora el certificado RAÍZ de la asignatura a la lista de autoridades reconocidas del sistema según las instrucciones.


\chapter{Configuración del servidor Apache}
Descripción detallada de los ficheros modificados, donde se configuran el certificado de servidor, cliente (si fuera necesario) y la entidad CA (Autoridad de Certificación).


\chapter{Instalación y arranque del servidor Apache}
Comandos utilizados:
\begin{lstlisting}[language=bash]
sudo apt update
sudo apt install apache2
sudo a2enmod ssl
sudo systemctl restart apache2
\end{lstlisting}
Se revisan continuamente \texttt{/var/log/apache2/error\_log} para detectar *warnings* y errores; y \texttt{/var/log/apache2/access\_log} para comprobar accesos.

\chapter{Página index.html}
Creación de la página principal en el directorio raíz del servidor y configuración de los permisos y cualquier otra modificación adicional necesaria.

\chapter{Conexión con openssl s\_client}
Comprobación mediante \texttt{openssl s\_client}:
\begin{lstlisting}[language=bash]
openssl s_client -connect www.ejemplo.com:443
\end{lstlisting}
Se compara con al conexión a \texttt{www.ulpgc.es:443} para verificar. Así nos aseguramos de que no hay un problema de identificación del servidor y los certificados que presenta.

\chapter{Conexión desde el navegador local}
Se realizan pruebas con Firefox, donde deberá accederse de forma transparente, es decir, sin mostrar ningún error y sin generar avisos con la opción de "\textit{Entiendo los riesgos}".

\chapter{Capturas de Pantalla del acceso web}
\textit{Se incorporarán las 4 capturas, como mínimo, que muestran la correcta configuración de la web de este servidor virtual:}
\begin{itemize}
    \item 2 capturas con el contenido para las descripciones de los dominios (ejemplo.com y www.ejemplo.com).
    \item 2 capturas de las propiedades de la conexión.
\end{itemize}
